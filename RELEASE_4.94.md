# RYZOD 4.94 — Live Picture Recovery

- After tuning live TV, watch for video that stops advancing while playback continues. The first recovery reconnects the video output to the existing player and stream.
- If the temporary pause reader disconnects, recover near the current playhead so a low-level retry cannot reopen the original pause offset.

Fire TV uses `RYZOD-v4.94-FireTV.apk`. Android and Android TV use `RYZOD-v4.94.apk`.

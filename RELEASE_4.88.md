# RYZOD 4.88 — Guide and Focus

- The live guide scrolls just far enough to reveal the next show when you move down with the remote. Nearby rows stay in view.
- The focused show or control fills pink with a bright border. Focused channel names and program titles use white text.
- The bottom-right settings gear has been removed from the movie and episode playback controls. App settings are available from the main menu.

Fire TV uses `RYZOD-v4.88-FireTV.apk`. Android and Android TV use `RYZOD-v4.88.apk`. Both are signed with the existing RYZOD release certificate so they can install as updates.

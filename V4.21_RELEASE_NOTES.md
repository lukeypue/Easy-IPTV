# EZTV v4.21 — Live Controller Cleanup + Download Queue

This is a refinement release. The smooth live playback, v4.20 DVR ingest/server rollback, USB recording path, VOD catalog loading, and app-owned VOD downloader are intentionally protected.

## Live TV
- The old live PlayerView/title controller is suppressed completely. Live TV has one controller: EZTV's mini guide.
- Mini guide now includes Record / Stop Recording and Picture Size in addition to Play/Pause, 30-second rewind/forward, CC, AFR, Smooth/DVR, Retry and Settings.
- Recording status is shown directly in the mini guide.
- Explicit Fire-TV D-pad focus map across rewind, play, forward, CC, AFR, mode, record, picture size, timeline and recent channels.
- Live DVR 30-second buttons are now separate explicit focus targets so selecting FF/RW cannot accidentally activate Play/Pause.
- Search results for live channels now reopen with the full live lineup and the correct channel index. Channel up/down and recent-channel return therefore work after launching a channel from Search.

## VOD / recordings focus
- Removed the focusable Compose title target that could trap the remote above Media3 controls.
- Added an explicit Fire-TV focus bridge from Media3's play row DOWN to the progress timeline and from the timeline UP to Play/Pause.
- If focus reaches EZTV's top VOD/recording row, D-pad Down returns to Media3 play controls.

## Downloads
- Download queue: customers can select multiple movies/episodes. EZTV still runs only ONE download socket/file writer at a time to stay light on Fire TV.
- Queued titles use no provider stream until they reach the front of the queue.
- Queue automatically advances when a download finishes/fails, and queued items survive normal app navigation.
- Downloads screen labels queued positions.
- Finished downloaded playback now asks Keep / Delete, matching recordings.

## Movies & Series
- Main Movies and Series browsers now use a five-column lazy poster wall with substantially larger artwork.
- Only visible grid rows are composed; this does not preload the entire catalog into RAM.
- Movies retain a compact download action on the poster.

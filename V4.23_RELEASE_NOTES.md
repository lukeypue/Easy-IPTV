# Zako v4.23 — Release Notes

This is the first Zako-branded build (formerly EZTV). The Android package name and legacy USB folder are intentionally unchanged so existing installs, recordings, downloads, and provider compatibility are not broken by the rebrand.

## Protected wins
- Smooth Live playback path is intentionally unchanged.
- Working USB recordings and the lightweight one-at-a-time download queue are preserved.
- Movie/Series poster wall, search-to-live lineup restoration, and Keep/Delete completion prompts are preserved.

## Live mini-guide
- Rebuilt as one compact control row instead of a half-screen panel.
- Initial focus is Play/Pause.
- Controls: Play/Pause, Record/Stop Recording, CC, DVR/Smooth, Size, Previous, Settings.
- Removed dead on-screen 30-second FF/RW boxes.
- Fire remote FF/RW now performs 10-second DVR jumps from anywhere in Live TV when DVR Live is active.
- Timeline Left/Right also performs 10-second jumps.
- PREVIOUS opens up to 8 actually watched channels; the list is hidden until requested.
- Normal guide height is much smaller; previous-channel cards expand only on demand.
- Timeline represents the scheduled program, shows the stored DVR section separately, and marks the current playhead.
- Exposed DVR history is limited to the most recent 45 minutes and resets on channel change.

## DVR reliability attempt
- New live-DVR-specific Media3 extractor path avoids native constant-bitrate seeking on the still-growing file.
- DVR playback waits for a small amount of TS data before Media3 starts parsing it.
- Localhost tune/seek starts are snapped to a nearby MPEG-TS PAT packet to help older Fire TV hardware relock.
- Viewer-selected channel changes now reset old DVR failure strikes instead of inheriting failures from the previous channel.
- Direct Rescue remains as a safety fallback so live TV is not sacrificed if DVR cannot lock.

## D-pad navigation
- Main Live guide: Left from a channel row returns focus to the category rail.
- Movies/Series: Left from the first poster column returns to the category rail.
- Changing category resets to the first poster at the top.
- Opening a movie/series and returning restores focus to the title you just left.
- Saved recording/download/VOD stock controls now hard-route Down from Media3 buttons to the progress bar and Up from the bar to Play/Pause.

## Search
- Fire TV keyboard now uses Activity adjustResize so the app content/results stay resized above the system keyboard instead of being fully covered where Fire OS honors it.

## Downloads discovery
- Movie category header explains: OK plays; hold OK queues a download.
- Long-OK on a movie queues it directly.
- Episode rows support long-OK to queue that episode as well.

## Rebrand
- App label is now Zako.
- New dark/electric-blue Zako launcher mark and Fire TV banner.
- User-facing EZTV wording was changed to Zako.

# EZTV v4.22 — Remote Navigation + DVR Timeline Polish

This release deliberately leaves the stable live playback, USB recording, VOD catalog, download queue and downloader core alone.

## Live mini-guide
- Rebuilt as a predictable 5-column x 2-row D-pad grid:
  - Row 1: Rewind 30 / Play-Pause / Forward 30 / Record-Stop / Size
  - Row 2: CC / AFR / Smooth-DVR-Retry / Retry / Settings
- Play/Pause receives initial pink focus.
- Disabled DVR buttons remain focusable, so Left/Right never hits a dead end; pressing them explains why DVR is unavailable.
- DIRECT RESCUE is now explicit. The mode button says `DVR RETRY` instead of misleadingly saying DVR LIVE.
- DVR fallback waits longer before abandoning a healthy, still-growing local timeshift writer.

## X1-style live timeline
- The timeline now represents the whole current program using EPG start/end times.
- Gold = elapsed program time.
- Cyan = the portion actually stored in EZTV's DVR/timeshift buffer.
- Pink dot = current viewing position.
- Text shows when the DVR buffer began and how far behind Live the viewer is.
- While the timeline is focused, Left/Right performs 30-second DVR jumps.

## Recordings / downloaded playback
- Added an Android View focus graph to Media3's stock VOD/recording controller.
- Any focused stock control can move Down back to the seek/progress bar.
- The progress bar moves Up to Play/Pause.
- This targets the Fire OS focus trap where users could move upward but could not return to the bottom timeline.

## Protected wins
No intentional changes to:
- Smooth Live playback engine
- USB recording/storage path
- app-owned VOD downloader and queue
- Movies/Series poster wall
- search-launched Live TV identity/channel surfing
- post-play Keep/Delete prompts

# Zako 4.44 — Download Stability

- Preserve partial movie/episode downloads after interruption or provider failure.
- Resume with HTTP Range when supported; safely restart at byte zero when the provider ignores Range.
- Reduce the transfer buffer to 64 KiB for Fire TV memory headroom.
- Keep existing Zako 4.43 DVR recording fix and 4.42 startup/search/3D behavior unchanged.

Release is published only after version/signing verification succeeds.

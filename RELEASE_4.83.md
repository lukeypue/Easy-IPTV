# RYZOD 4.83 — Colors

Version 4.83 · Android version code 107 · package `com.easyiptv.player`.

- Live TV, Movies, Series and the other primary navigation bubbles use warm orange.
- Favorites, Main menu and channel/movie/series category bubbles use silver.
- Guide channel bubbles use light Carolina blue instead of orange.
- Menu/channel lettering uses deeper gold for readability on the lighter fills. Program titles and gold accents use warmer gold instead of bright yellow.
- Selected items retain distinct fills, borders and font weights. Existing remote focus outlines stay visible.

All 4.82 playback, Smooth, saved-guide and search-retention behavior is retained.

Install `RYZOD-v4.83.apk` for Android/Android TV or `RYZOD-v4.83-FireTV.apk` for Fire TV. The package and permanent signing identity are unchanged.

The release requires the complete Android and Fire TV regression suites, lint, signed package verification and native 16 KB alignment checks. Amazon/Play candidates are retained as workflow artifacts only and are not submitted to stores. Physical-device appearance and provider playback still require device validation.

RYZOD 4.70 uses one guide cell per provider program, sized by its actual start and end time. Missing-guide gaps remain selectable for manual recording.

The guide has an Update Guide button and explains that program information comes from the provider and may take 1–2 minutes or longer to load. A failed refresh keeps the previous guide.

Live channels play directly without automatic disk DVR. Pressing Pause starts a channel-owned temporary recording; Play resumes it. Guide program boundaries and switching between the guide preview and full screen do not reset that recording. Temporary history is bounded to 30 minutes and available disk space. Channel selection, Stop, or Return to Live releases it unless an explicit recording owns the stream.

Wide RYZOD artwork is exposed as the default legacy launcher icon, activity logo and TV banner, including when a Fire TV launcher loads resources without the television qualifier. The square round-icon resource remains available to phone launchers.

The release compiles checked-in source directly. Signing/package identity and the full automated regression suite must pass before publishing. Both updater manifests point to the same signed build. Physical Fire Stick launcher caching, real provider playback and a 20-minute pause crossing a program boundary require device testing.

# Zako v4.23 — Test These First

1. Confirm GitHub Actions builds green and Fire TV shows the Zako name/banner.
2. Confirm ordinary Smooth Live is still as steady as v4.22.
3. Turn on DVR Live on a known-good channel. The picture should lock within a few seconds instead of immediately falling into Direct Rescue.
4. Pause Live TV for 5–10 seconds. Press the remote REWIND button once; it should move backward within the stored window. Press FF once; it should move toward Live.
5. Open the mini-guide with one OK press. It should be much shorter than v4.22 and start on Play/Pause.
6. Move Left/Right across every control and Up/Down to/from the timeline. There should be no focus dead end.
7. Select PREVIOUS. Confirm up to 8 actually watched channels appear and OK tunes them.
8. In the main Live guide, press Left from a channel row. Focus should return to the left category rail.
9. Movies: enter a category. Focus should start on the first poster. Scroll down, switch categories, and confirm the new category starts at the top. Open a movie and Back out; focus should return to that same movie.
10. Series: repeat the same category/focus test.
11. Hold OK on a movie poster and on an episode row; it should add the item to the existing download queue.
12. Search while the Fire keyboard is open. Confirm results remain visible above/behind the resized keyboard area better than before.
13. Play a saved recording/download, move Up into Media3 controls, then press Down. It should return to the progress bar.

If DVR still falls to Direct Rescue, take one photo of the mini-guide status immediately after selecting DVR Live and note roughly how many seconds it took before rescue. Do not change other playback settings for that test.

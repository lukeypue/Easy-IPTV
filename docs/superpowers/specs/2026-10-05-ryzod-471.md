# RYZOD 4.71 design

Continue Android/Fire Stick 4.70 (637c449). User requested completion through next update without further approval.

- Shared keyboard matches reference: ten-column digits/alphabet, symbols, accented letters; case, page, space, delete, clear and close controls, remote wrap. Orange translucent surface, top aligned for search with results visible below. All existing input fields use the same keyboard.
- Search from the first character, preparing normalized catalog/guide entries off UI once per data revision. Queries are cancellable, results bounded and ranked without sorting every match; show catalog results without waiting for guide work.
- Guide opens at the current time. Up/down selects first visible program beside destination channel, independent of previous block width; left/right explores duration-sized blocks, advancing two-hour windows through 72 hours. Remove Earlier/Now/Later controls. Orange channel cells, unchanged program distinction. Missing guide remains selectable.
- Manual recording offers 30,60,90,120,150,180,210,240,270,300 minutes and shows start/end in confirmation. Retain seven days and five-minute starts.
- Recording retries disconnect, EOF and silent connection until original stop; saves received bytes, bounded reconnect backoff and explicit low-storage stop. Cancel pending network on stop/deadline. Keep schedules until end or explicit stop/cancel; rearm/recover on boot/update/foreground; duplicate starts must not truncate a recording. Recover persisted ongoing recording on process restart and device restart. No missed footage can be reconstructed.
- Background recording must not prepare, resume or unmute hidden playback. Returning to app can resume viewing explicitly through activity lifecycle. Retain one-stream ownership.
- Reuse permanent signing identity, compile exact checked-in source, publish updater only after signed release verification. Keep pause-only DVR, Apple and Roku unchanged.

## Evidence and limits
Existing retry loop ends on clean EOF, stops after five exceptions, has infinite network read timeout. AlarmReceiver deletes schedules on start and cleanup deletes schedules five minutes after start. Recording preparation requests playback=true regardless of background state. Guide relies on geometric focus. Search normalizes and sorts all candidates per query and rejects one letter.
Physical Fire Stick, real provider and power/network tests remain device validation; automated tests exercise actual service/Compose/network behavior where supported.

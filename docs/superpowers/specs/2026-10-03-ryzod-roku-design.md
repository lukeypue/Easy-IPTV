# RYZOD Roku port

## Intent and baseline
Luke requested the same RYZOD app on Roku, on its own branch, using the last Android/APK source, and asked for repeated verification before delivery. Source: released Android 4.70 / build 94, commit 637c449f79db1f2d784d0561041a06be750c779b. Preserve Android and Apple source. Roku lives entirely under `roku/`, with an independently scoped CI workflow. Native BrightScript + SceneGraph, HD logical canvas, same artwork, colors and eight root menu entries. No demo provider, channel bundle, or credentials shipped.

## Architecture
- Pure BrightScript domain code: provider normalization, playlist parsing, EPG geometry and gaps, scoped favorites, resume, keyboard/navigation and item actions. The same code executes in the headless BrightScript interpreter for tests.
- SceneGraph UI: persistent menu, native video node shared by preview/fullscreen, branded login, three-page wrapped keyboard, live duration-based timeline, movies/categories, series/seasons/episodes, scoped search, favorites, playlist manager, settings, recordings/downloads.
- Task nodes own all network requests. Requests have generation IDs, timeouts and cancellation. Stale responses cannot overwrite a newer playlist/page. Failed guide refresh retains old data. One Video node prevents duplicate provider connections.
- Roku registry: at most three playlists plus bounded favorites/resume; reject writes over 28 KB, and preserve valid prior state. Provider passwords never logged or included in package. Saved data is device-local, not a secure vault.
- Optional LAN companion: Python standard-library HTTP server and persistent SQLite job store. Authenticated requests, no CORS, no credentials in logs. Direct stream recording, queued resumable file downloads, seven-day schedules, retries, stop/delete confirmation on Roku, authenticated Range playback. Jobs persist across restart. Roku cannot write USB or run Android background services; local storage operations use this companion. It requires an always-on computer/NAS, and does not run in Roku itself.

## Matching behavior
Three playlists; Xtream username/password and M3U link. Provider categories, live channels, movies, series, episode lists, favorites and resume. Main rail: Live TV, Movies, Series, Search, Downloads, Recordings, Playlists, Settings. Watch/Play first and Close last in horizontal item action row. Back restores guide channel and category position. Empty EPG cells remain selectable; manual recording permits a date within seven days, hour 0–23 and five-minute steps, with explicit confirmation and end/duration selection. Guide refresh explains provider ownership and loading delay. Existing playback continues while browsing the guide as a focusable preview. Mini guide shows current channel/program, progress, previous channel, pause/play, live return, stop and options.

## Roku-specific constraints
Native live pause depends on Roku's buffer and provider manifest; no guaranteed 30-minute disk buffer. Return to Live restarts the same stream; changing channels clears native pause state. HLS preferred for Xtream live; a manual stream-format setting offers TS. Codec compatibility depends on the Roku model; no FFmpeg decoder inside the Roku app. Persistent DVR and downloads require the optional companion and remain visible with a clear setup message when it is absent. Roku developer updates are sideloaded ZIPs, not APKs; public distribution needs separate store review. No promise of store acceptance or real-device performance from host checks.

## Verification
Run pure production BrightScript under `brs` against malformed/empty provider data, wrapped arrays, encoding, M3U metadata, XMLTV time offsets, overlapping EPG/clipping/gaps, D-pad wrap, playlist isolation, action order, resume boundaries and manual schedule range. Compile all SceneGraph XML/scripts with BrighterScript. Validate package paths, field observers, callbacks and assets. Exercise companion HTTP auth/Range, schedule persistence, pause/resume queue, retries, deletion, stopping and process restart against a local stream fixture. Re-run suites after integration and after review fixes. Build ZIP deterministically, inspect packaged assets and verify checksums. Real Roku playback, native focus, captions/audio selection, pause duration and long soak require a physical Roku and user provider credentials.

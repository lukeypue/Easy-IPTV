# EZTV v4.19 — Release Notes

## Goal
Protect the now-smooth Live TV path while fixing the live controller/DVR usability, provider connection limits, recording coexistence, and Movies/Series/Search.

## Live TV controller / mini guide
- Media3's stock controller is disabled for Live TV. There is now one EZTV controller only.
- A normal single press of OK opens the EZTV controller; holding OK is not required.
- Play/Pause receives initial D-pad focus and the existing hot-pink focus treatment.
- Explicit up/down focus routes connect the header, controls, DVR bar and recent-channel row to prevent the old focus traps.
- Controller stays visible for 15 seconds while playing and stays open while paused.
- Current channel logo, current/next program, recents, CC, AFR, Smooth/DVR status and provider-stream setting are visible together.

## DVR Live
- DVR HTTP tail-follow server now supports byte-range requests and exposes a bounded virtual length so Media3's progressive MPEG-TS seeker can seek in already-recorded material.
- The mini-guide has a real DVR session bar: DVR start → playhead → LIVE.
- Left/Right on the DVR bar and the remote FF/RW keys jump 30 seconds when the source is seekable.
- Smooth Live remains non-seekable and stays on the lightweight direct path.

## Provider streams: 1 / 2 / 3
- New Settings option for the number of simultaneous connections included with the customer's IPTV subscription. Default remains 1.
- Same-channel DVR recording tees from the existing timeshift file and costs no extra provider connection.
- With 2 or 3 configured streams, a recording may continue while the viewer changes to another live channel, and a download may run if another slot is available.
- With 1 stream, EZTV blocks/confirms conflicting actions instead of silently opening too many provider connections.

## Recording
- Recording the live channel being watched no longer intentionally stops playback; it shares the DVR source.
- If the viewer changes channels and the plan allows another stream, the recording switches to its own provider connection and continues.
- Recording and download ownership now use the same connection-budget rules.

## Movies / Series / Search
- Xtream Movies and Series are loaded sequentially on demand instead of parsing multiple huge API responses at once.
- One retry is built into the Xtream VOD/series API request.
- Handles several common Xtream response wrappers and series-episode JSON shapes.
- Movies/Series failures no longer disable Live search. Error text is specific to the on-demand catalog.
- Search remains usable for live channels even if the provider's on-demand endpoint fails.
- A VOD item rejected with HTTP 403/406 receives one browser-compatible User-Agent retry; Live TV is untouched.
- Tolerant MPEG-TS extraction remains VOD-only.

## Kept from v4.18.2
- Verified External/portable USB support and write test.
- User-selectable download retention including Keep until deleted.
- Channel logos and movie/series artwork.
- Closed captions toggle.
- AFR/frame-rate display and matching.
- Smooth Live and the live buffering improvements.

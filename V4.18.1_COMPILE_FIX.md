## USB decision
Do not rely on arbitrary root-level USB writes. EZTV uses Android/Fire OS app-scoped external storage and verifies it with a real write test. Portable/external USB can work when Fire OS exposes a writable app-specific directory; adopted/internal storage is a separate mode that makes the drive behave like device storage. See the accompanying response for the recommended format and tradeoffs.
